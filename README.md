# AjansLabs — Web Sitesi

Genç, modern, "kendisi bir portfolyo" olan creative ajans sitesi.
Tasarım yönü: sıcak-siyah zemin · asit-yeşili vurgu · kinetik dev tipografi · ritim/ses dalgası motifleri · asimetrik düzen.

## Çalıştırma
`index.html` dosyasına çift tıkla — tarayıcıda açılır. Sunucu gerekmez.

## Klasör yapısı
```
AjansLabs_web/
├── index.html              # Ana sayfa (Faz 1)
├── assets/
│   ├── css/styles.css      # Tasarım sistemi (renk, tipografi, grid, animasyon)
│   └── js/main.js          # Nav, scroll reveal, ses dalgası
└── README.md
```

## Tasarım anahtar kelimeleri
bold · dinamik · ritmik · çağdaş · deneysel · expressive · motion-first
Renk: warm black (#0c0c0a) + acid (#d8ff3e) + coral spark (#ff5a3c)
Font: Clash Display (display) + General Sans (body) — Fontshare
